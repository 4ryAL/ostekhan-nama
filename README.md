# Ostekhan Nama — Interactive Skeleton Atlas

A Persian-language, single-page interactive schematic of the adult human skeleton. Explore 206 individually selectable bones, separate or reassemble them with a slider, search by Persian or English anatomical name, and zoom in on smaller bones.

**Live app:** https://ostekhan-nama.af2000135790.chatgpt.site

## Run locally

Open `index.html` in a modern browser. No dependencies or build step are needed.

## Notes

This is a schematic educational illustration. Bone shapes and proportions are not intended for clinical use. The conventional adult count of 206 bones is used; individual variation exists.

## Technology

HTML, CSS, and vanilla JavaScript.
